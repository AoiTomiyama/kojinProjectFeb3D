## 会話を使わずタスク状態を再構成する

1. Chronos原本の各タスクから`id`・`uid`・`category`・`status`・`updated_at`と問題・解決策・結論を読む。表示IDの番号はカテゴリ内の順序で、uidは移行前の固定IDである。
2. uidに対応する実施記録を読む。旧D系は[設計レビュー](../tasks/program-design-review.md)、旧A系は[設計改善](../tasks/architecture-improvement.md)、旧R系は[セルフレビュー](../tasks/extensibility-self-review.md)、旧V系は[既存検証](../tasks/headless-verification.md)に根拠がある。最新のユーザー判断と原本の結論を優先する。
3. 関連する現行仕様・コードとGit差分を照合する。過去のテスト成功は、その記録にある版と実行条件の証拠として使う。文書照合と新たなゲーム検証を読み分ける。
4. 部分対応を確認する。CBT-12の死亡保証は完了しているが、CBT-03の体力共通状態クラス化は未着手。CBT-04が行動選択を担当し、SET-01は複数対象の参照仕様待ちである。
5. 新しい発見は根拠・問題・解決案をユーザーへ提示し、採用判断を受ける。採用済み判断を仕様・設計の正本へ記録し、共通CLIでタスク原本を更新する。

## VFX-01の廃止判断と差分処理

タグ: `VFX-01` `V-02` `廃止判断` `差分取消`

2026-10-14、ユーザーがVFX-01を破棄し、続く依頼でシェーダー・比較テスト・検証用設定・記録差分の取消と原本からの削除を指定した。処理の照合基点は`e3b959f`。タスクは31件から30件になり、残る項目のID・uid・状態・本文・日時・順序を保持した。

| 対象 | 処理と根拠 |
| --- | --- |
| 外部Trailシェーダーと.meta | 旧V-02記録にある4か所のpowガードと2行のコメントを除去。比較テストの元式復元処理とも一致する。両ファイルの追加ステージを解除し、従来のAssetStoreTools除外へ戻した。ローカルの元資産とGUIDは保持した。 |
| VfxShaderRenderingTests.csと.meta | 当該シェーダーの2素材比較専用で、未追跡だった2ファイルを削除した。 |
| URP設定3件とPlayerSettings | 旧検証記録が明記する検証時の自動書換えと照合し、基点HEADへ復元した。差分はURPのスキーマ・prefilter更新とPlayerSettingsの追加シリアライズ項目である。Unity・Packagesの採用済み更新`5ff6c5d`は保持した。 |
| 仕様と検証記録 | 未コミットのTrailガード仕様8行と修正・再実行計画を取り消した。既存の警告観測は過去の証拠として保持し、廃止記録への参照を付けた。 |

元シェーダーにはpow警告の観測がある。警告だけで表示不具合は確定しておらず、旧GPU比較はエラー描画のため無効だった。今回の取消確認は差分・式・GUID・参照・タスク保持の静的照合であり、Unityの描画を再検証した結果ではない。

設計図の2026-10-11/12時点の差分保護記録は当時の証拠として読む。現在の廃止状態は本節を正本とする。新担当は原本・仕様・コードと作業ツリーを照合する。会話だけに残る採用済み判断はなく、SET-01の未決定仕様は原本の結論から確認できる。
