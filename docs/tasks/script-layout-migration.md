## 検証

- Unity 2022.3.62f2付属のC#コンパイラーで、ゲーム用とEditor用の両アセンブリが終了コード0。応答ファイルをローカル一時ディレクトリへ複製して新しいパスを反映し、生成物を直接編集せず確認した。
- 最初のEditor検証は制限された環境でライセンス接続がタイムアウトし、終了コード199。ユーザーの権限変更後、Unity 2022.3.62f2のTest Runnerで4件成功・失敗0件、Editor終了コード0を確認した。最初の再試行では追加したテストが引数付きPlayOneShotを誤判定したため、テストのメソッド確認を修正して再実行した。
- 継続テストは型の解決、全ゲームPrefabの欠落スクリプトとボタン接続、全設定アセットの型、InGameシーンの欠落スクリプト・ボタン接続・初期UI・通知寿命を検証。結果XMLはローカル一時ディレクトリの `kojin-layers-verified.xml`、ログは `kojin-layers-verified.log`。GUIの手動目視、音の聴取、各敵の移動・射撃の操作確認は含まない。
- 文書の相対リンク100件に欠落なし。移行前の41件のメタデータはEditor起動後も内容が一致した。
- `ProjectAssetReferenceTests` を継続利用するテストとして追加し、ゲーム型の解決、Prefabの欠落スクリプトとボタンの呼び出し先、設定アセットの型を確認する。既存 `UiEventLifetimeTests` にシーンの欠落スクリプトとボタン接続の確認を追加した。
