## 成果と判断

11項目のID・表示・効果・候補条件を個別SOへ、項目一覧を `InGameUpgrades.asset` へ移した。既存のSOは初期能力値・武器・弾カタログを担当しており強化定義は存在しなかったため、初期設定を重複させず独立した強化一覧を追加した。専用Inspectorで一覧と項目を同じ画面から編集できる。

ボタンは一覧から既存Prefabを使って生成し、定義IDで表示と選択効果を対応付ける。追加は定義を作って一覧へ登録するだけで、UIの個別配置を要しない。シーンに保存されていた11ボタンとその追加表示列を除去し、旧ボタン・シーンの効果値は重複して保持しない。追加列の文言も定義へ移行した。

レベル・経験値・選択回数・トークンは従来の状態所有者に残し、共有SOに実行時状態を書き込まない。ボタンは起動時に選択先をBindし、再Bindでクリック購読を追加しない。再生成時は旧ボタンの接続解除・非表示・親からの分離を先に行い、選択や抽選の状態を維持する。選択済み候補の解除は効果適用より先に行う。

候補条件は有効設定と最低レベル。既存項目は全て有効・最低レベル0・繰返し取得可で、従来の抽選・再抽選・最大レベルの動作を維持した。GUIDは新規設定にだけ新しく割り当て、既存Prefab・シーン・スクリプトの.metaは維持した。

追加手順と正本は [強化一覧と動的UI](../specs/upgrade-catalog-and-ui.md)。表示と効果が既存段階で一致しない項目の調整は今回行っていない。
